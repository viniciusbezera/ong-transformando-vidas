# 🤝 ONG Transformando Vidas

Projeto web desenvolvido para a **ONG Transformando Vidas**, com o objetivo de apresentar as ações da instituição, projetos sociais e facilitar a captação de recursos e apoio.

---

## 📌 Sobre o Projeto

O site foi estruturado para ser simples, acessível e responsivo, permitindo que visitantes conheçam o trabalho da ONG e saibam como contribuir.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** — Estruturação do conteúdo
* **CSS3** — Estilização e layout
* **JavaScript** — Interatividade e comportamento da página
